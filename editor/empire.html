Empire Editor

Flytt figurer og ting, og endre tekstene på kortene. «Lagre» skriver theme.json rett til GitHub, og Vercel publiserer endringen etter omtrent ett minutt.

Du trenger et GitHub-token med skrivetilgang:
1. github.com → Settings → Developer settings → Fine-grained tokens
2. Repository access: kun BusAdventures
3. Permissions: Contents → Read and write
Empire Editor Åpne spillet ↗
Dra figurer og ting dit du vil ha dem. Det gule punktet er foten (ankeret). Musehjul eller + / − endrer størrelsen, piltastene flytter litt (med Shift: mer). Klikk på bakgrunnen for å redigere tekstene til rommet.
